## Journey Engine v1.1.0 - Release Notes

1. Added full gamepad navigation scheme to all menus with visual focus indicators.
2. Overhauled visual theme to a deep indigo/warm accent palette, applied consistently across all game elements.
3. Raised sprite batch limit to 4096 and implemented platform frustum culling for improved performance on the expanded level map.
4. Expanded world map to approximately 3× width for a more Metroidvania-scale experience.
5. Improved level editor minimap sizing and implemented a no-wrap text editor with a sticky legend.
6. Improved the CI Watch screen in the release TUI to display real-time job status with a collapsible panel.
7. Updated documentation links to point to the self-hosted docs site and added web redirects for clean URLs.
