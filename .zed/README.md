# Quick Start

### Running the Engine

**Native (Desktop)**
- Open the command palette and run `task: spawn`, then select `Run Native (Debug)`.
- For maximum performance, run `Run Native (Release)`.

**Web (Browser)**
- Run `Run Web Dev Server` to build WASM and start Vite.
- Open `http://localhost:5173`.
- For faster iteration, run `Quick Web Dev (skip WASM rebuild)`.

### Building

- **Full rebuild**: Run `Build All (Native + WASM + Web)`.
- **Native only**: Run `Build Native`.
- **WASM only**: Run `Build WASM`.

### Testing & Quality

- **Run tests**: Run `Run Tests`.
- **Clippy lints**: Run `Clippy (All)`.

## Zed Commands

1. **Run Tasks**: Command palette -> `task: spawn`
2. **Rerun Last Task**: Command palette -> `task: rerun`
3. **Debug**: Command palette -> `debugger: start`
