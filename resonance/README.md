# Resonance

A zero-dependency, `no_std` DSP audio synthesis primitive in Rust.

Resonance generates sound directly from CPU math with zero heap allocations, zero external dependencies, and zero reliance on floating-point trigonometry at runtime.

## Architecture

- **`no_std` Core**: The synthesis engine operates purely on stack-allocated fixed-size buffers.
- **Precomputed LUTs**: All waveform tables (Sine, Square, Triangle, Sawtooth) are generated by `build.rs` at compile time, eliminating the need for `std::f32::sin()` and enabling bare-metal usage.
- **Fixed-Point DSP**: Phase accumulators use `u32` math, generating `i16` PCM samples.
- **Sound & Patch Layers**: Provides both raw DDS oscillators and programmable ADSR envelopes to trigger named procedural patches (Kick, Snare, HiHat, Laser, etc.).

## Integration

Resonance is infrastructure and not an application. It has zero awareness of its sink.

```rust
use resonance::patch::{Patch, PatchVoice};

let mut voice = PatchVoice::new(44100);
voice.trigger(Patch::Laser);

// Poll samples in your audio thread or WASM worklet
while voice.is_active() {
    let sample: i16 = voice.next_sample();
    // write `sample` to your sink
}
```
